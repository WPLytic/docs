# Individual Session Explorer

The visitor list shows the tracked sessions. Each session keeps its traffic source, its [tags](../api/tags.md), the pages that were visited and the [events](../api/events.md) that were recorded.

Use it to see what happened in one visit, for example the pages and events before a goal was completed.

To limit the list to one group of visitors, use [filters and segments](filters-user-segments.md).
