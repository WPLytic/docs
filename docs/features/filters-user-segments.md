# Filters - User Segments

A filter limits the WPLytic reports to the visitors that match it, for example visitors with a specific role, traffic source or tag. A saved filter is a segment.

* Save the segments that you review often, so that you do not set the same filters again.
* When a segment is active, the visitor list contains only that segment. The statistics charts and goals use the same segment.
* [Tags](../api/tags.md) mark the sessions that you want to filter later, for example sessions from a campaign. See [Tracking UTM parameters](../guides/tracking-utm-parameters.md).

For a short video, see [visitor segmentation in WPLytic](https://wplytic.com/user-segments/).
