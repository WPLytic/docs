# Tracking and Privacy Settings

WPLytic stores the visitor stats in the MySQL database of your WordPress site. No third-party tracker is loaded on your website.

## Tracking settings

Go to **wp-admin -> WPLytic (in the sidebar) -> Tracking settings**:

* **Tracked user categories**: enable or disable tracking for visitors, logged in users and admins.
* **Tracked pages**: track all pages except the ones you select, or track only specific pages.

Click **Save** after each change. The guide [Tracking Current WordPress Site](../guides/tracking-current-wordpress-site.md) shows these settings.

## UTM parameters

By default, UTM parameters are not tracked and are removed from the saved URL. To keep them, see [Tracking UTM parameters](../guides/tracking-utm-parameters.md).
