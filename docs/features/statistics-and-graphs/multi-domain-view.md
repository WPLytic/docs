# Multi-domain view

WPLytic can track other websites besides the WordPress site it is installed on. Each website is a domain in the Domains dashboard.

To add a domain, click the **+** button in the Domains dashboard and put the given tracking snippet on all pages of that website. See [Tracking External Websites](../../guides/tracking-external-websites.md).
